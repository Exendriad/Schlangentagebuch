# Schlangenbuch

Tagebuch für Schlangen: Fütterungen, Häutungen, Fotos und To-dos. Läuft im Browser und als Home-Bildschirm-App auf iPhone und iPad (Safari: Teilen → „Zum Home-Bildschirm“).

Alle Daten bleiben lokal auf dem jeweiligen Gerät (IndexedDB), es gibt keinen Server und keine Synchronisation.
